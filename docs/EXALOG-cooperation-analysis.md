## 二、YQN 的牌（促成合作的核心思路）

### 🎯 战略定位

**不要把自己当成"报价机器"**。你的角色是帮 EXALOG 关掉他们 7 月没走成的货。

### 🃏 三层价值

| 层次 | YQN 的优势 | 对 EXALOG 意味着什么 |
|------|-----------|---------------------|
| 🔍 **比价层** | 300+ 船司实时运价 | PIL $550 / COSCO $570 之外，你还能给他们第三条、第四条路 |
| 🏗️ **执行层** | 7 港全国网络 + 20 年拉美线 | 宁波到盐田，一个对接人搞定，不用他们分别找 7 家代理 |
| 🛡️ **合规层** | 巴西 NF-e / HS / 正清经验 | 帮他们避坑——巴西海关一个字母不对就卡关 |

### 📋 促成路径（三步走）

```
第一周：确认存活货盘 → 针对 TOP 5 票出价 → 建立信任
第二周：走通 1-2 票试单 → 验证分润流程 → 固化合作模式
第三周起：跑量 → 每月固定货盘 → 成为 EXALOG 的中国独家合作方
```

### 🔑 关键原则

1. **先筛选，再报价** — 22 票不可能全活。先问清哪些还在，集中火力打 TOP 5
2. **比价不杀价** — 不跟 PIL/COSCO 拼低价，而是给更多选择（更快船期 / 更稳舱位 / 冻柜专业能力）
3. **利润定义要写死** — 50/50 是分什么？海运费差价？含不含 THC/港杂？第一票就要白纸黑字
4. **MBL 价格问题要问，但不质疑** — 轻轻带过，"是合规要求还是客户偏好？"看对方反应
