## 产品介绍

做货代，客户开发有三难：**找不到精准客户、开发信千篇一律没回复、发了多少封跟进了谁全凭脑子记。**

Prospector 就是解决这三个问题的桌面工具：

| 痛点 | Prospector 怎么解决 |
|------|-------------------|
| 不知道客户靠不靠谱 | 一键背调，自动搜索公司官网、新闻、进口特征，生成中文报告 |
| 开发信写不出来、写不好 | 基于背调结果，逐家生成定制化开发信，支持**英语 / 西班牙语 / 葡萄牙语** |
| 发了就忘、跟进混乱 | 收件箱自动匹配回复、CRM 管道追踪每家公司所处阶段、数据看板一目了然 |

**适用场景：** 拉美航线货代销售、跨境电商物流 BD、外贸业务员日常客户开发。

**运行环境：** Windows 桌面应用（macOS 后续支持），下载安装包双击即用。

### ✍️ 智能开发信

不是冷冰冰的模板填空。基于背调数据，AI 为每家公司单独定制开发信内容——提到对方具体的业务、港口、品类，大幅提高回复率。

内置 **15 套预设模板**（直客 / 同行 / 潜在 × 初次接触 / 跟进 / 促单），也可以通过自然语言自由调整语气和内容。

支持三语：**EN（英语）/ ES（西班牙语）/ PT（葡萄牙语）**，按目标国家自动匹配。

### 📧 批量发送

写好开发信后，一键加入发送队列。Prospector 自动处理：

- **智能延迟** — 模拟人工发送节奏，不会 1 秒 50 封触发风控
- **工作时间窗口** — 只在设定时段内发送，避免深夜发出
- **自动暂停** — 到达每日上限自动停，第二天继续
- **断点续发** — 关闭程序也能接上进度

## 快速上手

### 1. 安装

从 [Releases 页面](https://github.com/Miloglim/Prospecting-Email/releases) 下载最新版安装包（`prospecting-email-send-setup-x.x.x.exe`），双击安装即可。

### 2. 配置

首次启动后，在 **设置** 页面配置：

- **SMTP 发信邮箱** — 用于发送开发信的邮箱账号
- **IMAP 收信邮箱** — 用于接收回复的邮箱账号
- **AI 服务** — 用于背调和开发信生成（支持 DeepSeek 等兼容 OpenAI 接口的服务）

### 3. 导入客户表

准备一份 Excel/CSV 文件，至少包含「公司名」列。额外的网站、国家、品类能大幅提升背调精度。

在应用内点击 **导入客户表**，选择文件即可。

### 4. 开始背调、写开发信

选中要背调的公司 → 点击 **背调** → AI 自动搜索并生成报告 → 点击 **生成开发信** → AI 基于背调生成定制内容。

### 5. 发送、追踪

开发信确认无误后 → **加入队列** → 点击 **开始发送** → 在 **收件箱** 和 **CRM 管道** 中持续追踪回复和进展。

## 常见问题

**Q: 支持哪些邮箱？**
A: 只要支持 SMTP/IMAP 的邮箱都可以。Gmail 需要开启「应用专用密码」，Outlook 和大部分企业邮直接填账号密码。

**Q: 一天能发多少封？**
A: 取决于你的邮箱服务商限制。Prospector 本身不限量，内置了智能延迟和每日上限保护，防止被标记为垃圾邮件。一般建议单账号每天不超过 200-300 封。

**Q: 支持什么语言？**
A: 开发信支持 **英语 / 西班牙语 / 葡萄牙语**。应用界面目前是中文。

**Q: 客户数据安全吗？**
A: 所有数据（客户表、背调报告、邮件往来）都存储在你本地电脑上，不上传到任何服务器。AI 调用走你配置的 API Key，直接加密存储在你的 `.env` 文件中。

**Q: 需要联网吗？**
A: 背调、AI 生成开发信、收发邮件需要联网。本地数据管理（查看客户、编辑模板、管道拖放）离线可用。
